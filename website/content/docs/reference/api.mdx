## Where to start in each

| You want | Python | TypeScript | Rust |
|---|---|---|---|
| An agent | `Agent` | `Agent`, `AgentOptions` | `criogenai_agent::AgentBuilder` |
| A tool | `@tool`, `ToolError`, `ToolContext` | `tool()`, `ToolDefinition`, `ToolError` | `tool_fn`, `ToolSpec`, `ToolError` |
| A conversation | `Thread`, `Reply` | `Thread`, `Reply`, `Stream` | `Thread`, `Reply`, `ThreadStream` |
| Storage | `Storage`, `Memory` | `Storage`, `Memory` | `criogenai_storage::Storage`, `Memory` |
| Models | `OpenAI`, `Anthropic`, `Gemini`, `Azure`, `Bedrock`, `Vertex`, `Ollama`, `OpenAICompatible`, `FakeModel` | `openai()`, `anthropic()`, `gemini()`, `azure()`, `bedrock()`, `vertex()`, `ollama()`, `FakeModel` | `ProviderModel`, `Endpoint`, `AzureModel`, `VertexModel`, `FakeModel` |
| Errors | `CriogenError` and subclasses | `CriogenError`, `isCriogenError` | `AgentError`, `RunError`, `StorageError` |
| Workflows | `Workflow`, `CompiledWorkflow`, `WorkflowThread` | `Workflow`, `CompiledWorkflow`, `WorkflowThread` | `criogenai_core::WorkflowBuilder`, `Storage::workflow_thread` |
| Patterns and specialists | `criogenai.patterns`, `criogenai.specialists` | `patterns`, `specialists` | `criogenai_agent::patterns`, `criogenai_agent::specialists` |
| Web search and page reading | `criogenai.web` | `web` | `criogenai_agent::web` (feature `web`) |
| Tools from MCP servers | `criogenai.mcp` | `mcp` | `criogenai_agent::mcp` (feature `mcp`) |
| Documents searched by meaning | `Collection` | `Collection` | `criogenai_agent::retrieval` |
| Evals | `criogenai.evals` | `evals` | `criogenai_agent::evals` |
| The local trace viewer | `criogenai.trace` | `serveTraces` | `criogenai_trace` |
| Gateway | `Gateway` | `Gateway` | `criogenai_gateway::Gateway`, `Config` |

Once the crates are on crates.io, the Rust reference will also be on
