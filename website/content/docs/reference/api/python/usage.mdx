## estimate_cost

```python
def estimate_cost(
    result: Any,
    prices: Mapping[str, Mapping[str, float]],
) -> Optional[float]
```

Estimates what a run cost in USD, from prices you supply.

Criogen ships no prices (they change too often). Cached input tokens
are charged at `cache_read` (or `input` when it is missing).
Reasoning tokens count as output tokens.

**Parameters**

- `result` (`Any`): A `RunResult` or `Reply`; its `models` field is read.
- `prices` (`Mapping[str, Mapping[str, float]]`): USD per million tokens for each model, keyed by `"provider:model"` or by model name: `{"input": ..., "output": ..., "cache_read": ...}` (`cache_read` is optional).

**Returns:** The cost in USD, or `None` when a model the run used has no price.

**Example**

```python
from criogen import Agent, FakeModel, estimate_cost

result = Agent(FakeModel(["Hello."])).run_sync("Hi")
cost = estimate_cost(result, {"fake": {"input": 0.25, "output": 2.0}})
print(f"{cost:.8f} USD")
```
