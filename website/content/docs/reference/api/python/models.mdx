## Models

Models: real providers, and `FakeModel` for tests.

Each turns into a small JSON spec the Rust engine builds the model from.
Strings work too: `"openai:gpt-5-mini"` takes its key from
`OPENAI_API_KEY`, `"deepseek:deepseek-chat"` from `DEEPSEEK_API_KEY`
(every name in `_KEYS`, plus `ollama`, `lmstudio` and `kaggle`).

### FakeModel

```python
class FakeModel:
    def __init__(
        self,
        replies: Sequence[Union[str, FakeReply]] = (),
        delay: float = 0.0,
        fail_first: int = 0,
        by_turn: bool = False,
        name: Optional[str] = None,
    )
```

A simulated model for tests: answers with the scripted replies in
order (a string is a text reply), then echoes. Never a network call.
`fail_first`: the first n calls fail with `rate_limited` (a
transient error the agent retries), to test retries. `by_turn`: choose
each reply by the conversation's turn (the first reply for a run's first
model call, the second for its second, then the last repeats) instead
of using replies up, so one model serves many runs, also at once.
`name`: the model name in replies (`"fake:<name>"`), to tell two
fake models apart.

### Kaggle

```python
class Kaggle:
    def __init__(
        self,
        model: str,
        api_token: Optional[str] = None,
        proxy_url: Optional[str] = None,
        proxy_token: Optional[str] = None,

```

Kaggle's Model Proxy: the hosted models your Kaggle
account's AI-model allowance pays for, e.g.
`Kaggle("google/gemini-3.6-flash")` or `"kaggle:google/gemini-3.6-flash"`.

Credentials, in order: `api_token` (a Kaggle API token); `proxy_url`
and `proxy_token` (a proxy token minted elsewhere, as in a Kaggle
notebook); else the environment: `MODEL_PROXY_URL` and
`MODEL_PROXY_API_KEY`, `KAGGLE_API_TOKEN`, or the `access_token` file
in `KAGGLE_CONFIG_DIR` or `~/.kaggle`. The engine mints the short-lived
proxy token and renews it before it expires. For prototypes and tests,
not production traffic (see the models guide).

`api` forces one (`"chat"`, `"claude"`).

### Azure

```python
class Azure:
    def __init__(
        self,
        model: str,
        endpoint: Optional[str] = None,
        api_key: Optional[str] = None,
        token: Optional[str] = None,
        tenant_id: Optional[str] = None,
        client_id: Optional[str] = None,
        client_secret: Optional[str] = None,
        managed_identity: bool = False,
        api: str = 'responses',
        scope: Optional[str] = None,
        authority: Optional[str] = None,
        identity_endpoint: Optional[str] = None,
    )
```

Azure OpenAI or Microsoft Foundry: a deployment,
e.g. `Azure("gpt-5-mini", endpoint="my-resource")` or
`"azure:gpt-5-mini"`. The model name is the deployment name.

`endpoint` is the resource name or URL (else `AZURE_OPENAI_ENDPOINT`).
Credentials, in order: `api_key`; `token` (a bearer token from
elsewhere); `client_secret` with `tenant_id` and `client_id` (a
service principal); `managed_identity=True` (with `client_id` for a
user-assigned identity); else the environment: `AZURE_OPENAI_API_KEY`,
or `AZURE_TENANT_ID` + `AZURE_CLIENT_ID` + `AZURE_CLIENT_SECRET`, or
`AZURE_USE_MANAGED_IDENTITY=1`. Entra ID tokens are obtained and renewed
by the engine. `api="chat"` for Foundry's models from other makers.

## Gateway

Calling a model without an agent: `Gateway`.

```python
gw = Gateway(fallbacks=["gemini:gemini-2.5-flash"])
reply = await gw.chat("openai:gpt-5-mini", "Summarize: …", instructions="Be brief.")
print(reply.text)
```

Retries and fallback models work as for an agent, in the Rust engine.

```python
from criogen import Gateway, ChatReply, Chunk, ChatStream
```

### Gateway

```python
class Gateway:
    def __init__(
        self,
        *,
        fallbacks: Sequence[Any] = (),
        fallback_on: Sequence[str] = (),
        retry: Optional[Retry] = None,
        max_retry_after: Optional[float] = None,
    )
```

Model calls without an agent: `chat`, `stream` and `embed`,
with the agent's retries and fallback models.

`fallbacks`: models tried in order when the one asked for fails with a
transient error (after its retries); `fallback_on`: other error kinds
that also move on (e.g. `"context_overflow"`); `retry`: how transient
errors are retried; `max_retry_after`: the longest `Retry-After` that
is waited for, in seconds.

#### Gateway.chat

```python
async def chat(
    model: Any,
    input: Input,
    *,
    instructions: Optional[str] = None,
    temperature: Optional[float] = None,
    max_tokens: Optional[int] = None,
    output: Any = None,
) -> ChatReply
```

One answer. `input`: text, or messages (`content` may be a
string). `output`: a JSON Schema (or a Pydantic model) the answer
must match; `reply.output` is then the parsed JSON.

## Keys and environment

API keys from the environment, and a `.env` file to keep several in.

Each provider reads its key from its usual variable, so you can keep all of
them side by side and switch models by changing a string:

```python
OPENAI_API_KEY      `"openai:gpt-5-mini"`
ANTHROPIC_API_KEY   `"anthropic:claude-sonnet-5-5"`
GEMINI_API_KEY      `"gemini:gemini-2.5-flash"`
OPENROUTER_API_KEY  `"openrouter:meta-llama/llama-3.3-70b-instruct"`
DEEPSEEK_API_KEY    `"deepseek:deepseek-chat"`
GROQ_API_KEY        `"groq:llama-3.3-70b-versatile"`
```

and the same for `mistral`, `xai`, `cerebras`, `together`,
`fireworks`, `qwen` (`DASHSCOPE_API_KEY`), `moonshot` and `zai`
(`key_name(provider)` gives the variable).

`load_env()` reads a `.env` file into the process environment (call it
before you build a model). It never prints or returns a value, and never
replaces a variable that is already set unless you ask.

```python
from criogen import env

env.parse_env(...)
from criogen import load_env
```

These are used as `env.<name>`. Also exported at the top level: `load_env`.

### parse_env

```python
def parse_env(text: str) -> Dict[str, str]
```

Parse `.env` text: `NAME=value` lines, `export NAME=value`, `#`
comments, and values in single or double quotes. No variable expansion.
A malformed line raises `ValueError` naming the line number (never its
content: it may be a secret).

### load_env

```python
def load_env(
    path: Union[str, 'os.PathLike[str]'] = '.env',
    *,
    override: bool = False,
    required: bool = False,
) -> List[str]
```

Read a `.env` file into `os.environ` and return the NAMES it set
(sorted; never the values).

- A variable that is already set is kept, unless `override=True`.
- A missing file is fine (returns `[]`), unless `required=True`.
- Files over 1 MB are refused.

Keep the file out of git (add `.env` to `.gitignore`).
