## Agents

Agents and threads over the Rust engine.

```python
from criogen import (
    Agent,
    Thread,
    Stream,
    Reply,
    RunResult,
    Decision,
    ApprovalRequest,
    Retry,
    AgentTool,
    Event,
)
```

### Agent

```python
class Agent:
    def __init__(
        self,
        model: Any,
        *,
        instructions: Optional[str] = None,
        tools: Sequence[Any] = (),
        approve: Sequence[str] = (),
        output: Any = None,
        limits: Optional[Dict[str, Any]] = None,
        storage: Union[None, str, Storage] = None,
        memory: Optional[Memory] = None,
        on_tool_exception: Optional[str] = None,
        fallbacks: Sequence[Any] = (),
        fallback_on: Sequence[str] = (),
        model_retry: Optional[Retry] = None,
        tool_retry: Optional[Retry] = None,
        max_retry_after: Optional[float] = None,
        telemetry: Any = None,
        hooks: Sequence[Any] = (),
        redact: Any = None,
    )
```

A model with tools, instructions and (optionally) approval, typed
output, storage and memory. The loop runs in Rust.

`on_tool_exception`: what happens when a tool raises an exception it
did not handle (`ToolError` always goes to the model):
`"return_to_model"` (default; the model sees the exception's type and
message, the run goes on), `"return_generic"` (the model only learns
that the tool failed; the text stays in the result's `artifact`) or
`"fail"` (the run fails with `ToolExecutionError`, the exception as
its `__cause__`).

## Tools

Tools: Python functions the engine calls.

The schema comes from the type hints; the Rust engine validates the
model's arguments against it before the function runs.

```python
from criogen import tool, Tool, ToolError, ToolContext
```

### tool


## Hooks

Hooks: code that runs around the agent loop, in order.

A hook is any object with some of these methods (each sync or async):

- `on_start(ctx)`: once per run segment; may return `HookAction(state=…)`.
- `before_model(ctx)`: before each model call; may replace the
  transcript (`HookAction(messages=[…])`) or end the run.
- `after_model(ctx)`: after each model reply (`ctx.messages` ends with
  it); may replace it (`HookAction(message={…})`) or end the run.
- `before_tool(call)`: before each tool call; may return a changed
  `ToolCall`, a `ToolResult` to skip the tool, or raise `ToolError`.
- `after_tool(call, result)`: after each tool call; may return a
  replacement result.
- `on_end(ctx, outcome)`: always, once per segment (`"completed"`,
  `"suspended"` or `"failed"`); cannot change the outcome.

`on_start`, `before_model` and `before_tool` run in list order, the
others in reverse. An exception in `on_start`, `before_model` or
`after_model` fails the run with `hook_failed` (the exception is its
`__cause__`); one in `before_tool` / `after_tool` counts as the tool's
(see `on_tool_exception`). Hook methods run on your event loop: keep sync
ones quick.

```python
from criogen import HookContext, HookAction, ToolCall, ToolResult
```

## Usage and cost

What a run cost: which models answered, with their calls and tokens (from
the engine's per-message metadata), the call's wall time, and a cost estimate
from prices the caller supplies (they change too often to ship).

```python
from criogen import estimate_cost
```

### estimate_cost

```python
def estimate_cost(
    result: Any,
    prices: Mapping[str, Mapping[str, float]],
) -> Optional[float]
```

The cost of a run in USD from your prices (USD per million tokens:
`{"input": .., "output": .., "cache_read": ..}`), keyed by
`"provider:model"` or by model name. `None` when a model that was used
has no price. Reasoning tokens count as output tokens.

## Errors

Errors: one class per family, each with the stable
`code` the Rust engine uses, so checks by code work in
every language.

```python
from criogen import (
    CriogenError,
    ModelError,
    ToolExecutionError,
    LimitExceededError,
    ThreadBusyError,
    ThreadSuspendedError,
    StorageError,
    ValidationError,
    CancelledError,
)
```

### CriogenError

```python
class CriogenError(Exception):
    def __init__(self, code: str, message: str, details: Optional[Dict[str, Any]] = None)
```

Any Criogen failure. `code` is stable; `details` is JSON.
