Every error class, one per stable error code. Generated from the docstrings and type hints of `criogenai` 0.1.7. See also: [Python API overview](/docs/reference/api/python/), the same module in [TypeScript](/docs/reference/api/typescript/errors/).

Errors: one exception class per family of failures.

Every exception carries the stable `code` the Rust engine uses (for
example `model_failed` or `thread_busy`), the same in every language;
the error reference (/docs/reference/errors/) lists them all. Catch a class for a
family, or compare `error.code` for one failure.

```python
from criogenai import (
    CriogenError,
    ModelError,
    ToolExecutionError,
    LimitExceededError,
    ThreadBusyError,
    ThreadSuspendedError,
    StorageError,
    ValidationError,
    CancelledError,
)
```

## CriogenError

```python
class CriogenError(Exception):
    def __init__(self, code: str, message: str, details: Optional[Dict[str, Any]] = None)
```

Any CriogenAI failure; the base class of the others.

The engine raises these; you rarely build one yourself. `str(error)`
is `"<code>: <message>"`.

**Parameters**

- `code` (`str`): The stable snake_case error code, such as `"model_failed"`.
- `message` (`str`): What went wrong, for people.
- `details` (`Optional[Dict[str, Any]]`, default `None`): More about the failure as a JSON-like dict (it may hold the run's `snapshot`). Default `{}`.

**Example**

```python
from criogenai import CriogenError, LimitExceededError

try:
    result = agent.run_sync("Plan the week.")
except LimitExceededError:
    print("the run hit a limit")
except CriogenError as error:
    print(error.code, error.message)
```

### CriogenError.snapshot

```python
snapshot: Optional[Dict[str, Any]]
```

The run's snapshot, if the error carries one.
