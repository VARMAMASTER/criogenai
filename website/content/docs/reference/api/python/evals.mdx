Datasets, scorers, judges, comparisons and quality gates. Generated from the docstrings and type hints of `criogenai` 0.1.7. See also: [Python API overview](/docs/reference/api/python/), the same module in [TypeScript](/docs/reference/api/typescript/evals/).

Evals: run an agent over a set of cases, score each answer, compare with the last good run, and fail CI when quality drops.

```python
from criogenai import evals

data = evals.Dataset.load("cases.jsonl")         # {"input": ..., "expected": ...} per line
result = await evals.evaluate(agent, data, [evals.contains(), evals.tool_called("lookup_order")])
print(result.report())
result.save("eval.json")
result.check(min_pass_rate=0.9, baseline=evals.EvalResult.load("baseline.json"))
```

The result file has the same format in Python, TypeScript and Rust
(`criogen-eval/1`), so a baseline saved by one is read by the others.

From the command line, `python -m criogenai.evals compare baseline.json current.json [--fail-on-regression]` prints both reports (see `main`).

Scorers get three things: the `Case`, the output, and *facts* about
the run, a dict with `tool_calls` (the names of the tools called, in
order), `model_calls`, `tokens` (`{"input", "output"}`),
`duration_ms` and `models` (each model used, with its `usage`). For a
function target, the facts are empty apart from `duration_ms`.

```python
from criogenai import evals

evals.evaluate(...)
```

These are used as `evals.<name>`.

## evaluate

```python
async def evaluate(
    target: Any,
    dataset: Union[Dataset, Iterable[Any]],
    scorers: Sequence[Scorer],
    *,
    name: str = 'eval',
    concurrency: int = 4,
    timeout: float = 120.0,
    repeats: int = 1,
) -> 'EvalResult'
```

Runs a target on every case and scores each output.

A case that raises or times out scores 0 on every scorer and keeps its
error; the eval goes on. A scorer that raises gives that case 0 with the
error as the reason.

**Parameters**

- `target` (`Any`): An `Agent` (called as `agent.run(case.input, **case.state)`; the output is the result's `output`, else its `text`) or a function `case -> output`, sync or async.
- `dataset` (`Union[Dataset, Iterable[Any]]`): A `Dataset`, or anything `Dataset` accepts.
- `scorers` (`Sequence[Scorer]`): At least one `Scorer`, with unique names.
- `name` (`str`, default `'eval'`): The eval's name, shown in reports and saved in the result. Default `"eval"`.
- `concurrency` (`int`, default `4`): Cases run at the same time, 1 to 64. Default 4.
- `timeout` (`float`, default `120.0`): The longest one run of a case may take, in seconds. Default 120.
- `repeats` (`int`, default `1`): Runs per case (for answers that vary). Each scorer's value is the mean over the runs, and the case passes only if every run passes. Default 1.

**Returns:** The `EvalResult`.

**Raises**

- `ValueError`: No scorers, or two with the same name.

**Example**

```python
from criogenai import Agent, FakeModel, FakeReply, evals, tool

@tool
def lookup_order(order_id: str) -> str:
    "Looks up an order's status."
    return "shipped"

agent = Agent(
    FakeModel([FakeReply.tool_call("lookup_order", {"order_id": "A1"}), "Order A1 has shipped."], by_turn=True),
    tools=[lookup_order],
)
data = evals.Dataset([{"input": "Where is order A1?", "expected": "shipped"}])
result = await evals.evaluate(agent, data, [evals.contains(), evals.tool_called("lookup_order")])
print(result.report())
```

## Dataset

```python
class Dataset:
    def __init__(self, cases: Iterable[Union[Case, Mapping[str, Any], str]])
```

The cases to run. Build one from a list, or `load` a JSONL or JSON file.

**Parameters**

- `cases` (`Iterable[Union[Case, Mapping[str, Any], str]]`): `Case` objects, dicts with `input` (a string) and optionally `expected`, `id`, `state` and `metadata`, or plain strings (an input with nothing expected). At most 100,000.

**Raises**

- `ValueError`: A case without a text `input`, duplicate ids, or too many cases.

**Example**

```python
from criogenai import evals

data = evals.Dataset([
    {"input": "Where is order A1?", "expected": "shipped"},
    {"id": "refund", "input": "Can I get a refund?", "expected": ["refund", "30 days"]},
    "Hello",
])
len(data)   # 3
```

## EvalResult

```python
class EvalResult:
    def __init__(self, data: Dict[str, Any])
```

An eval's outcome: a summary and one entry per case, in the `criogen-eval/1` format every language reads.

Each case entry holds `id`, `input`, `expected`, `output` (text
cut to 100,000 characters), `scores` (`{name: {"value", "pass", "reason"}}`), `pass`, `error`, `duration_ms`, `tool_calls`,
`model_calls`, `tokens` and, when set, `judge_tokens` and
`metadata`.

**Parameters**

- `data` (`Dict[str, Any]`): The result as a dict (from `evaluate`, or a saved file via `load`).

**Raises**

- `ValueError`: `data` is not in the `criogen-eval/1` format.

**Example**

```python
result.save("eval.json")
baseline = evals.EvalResult.load("baseline.json")
result.check(min_pass_rate=0.9, baseline=baseline)
```

### EvalResult.check

```python
def check(
    min_pass_rate: Optional[float] = None,
    min_scores: Optional[Mapping[str, float]] = None,
    baseline: Optional['EvalResult'] = None,
    max_regressions: int = 0,
    tolerance: float = 0.02,
) -> None
```

Raises `EvalFailed` when a bar is missed; use it to fail CI.

Every bar is checked and all misses are reported together.

**Parameters**

- `min_pass_rate` (`Optional[float]`, default `None`): The lowest pass rate allowed, from 0 to 1.
- `min_scores` (`Optional[Mapping[str, float]]`, default `None`): The lowest mean per scorer, e.g. `{"judge": 0.8}`. A name that is not a scorer of this eval fails too.
- `baseline` (`Optional['EvalResult']`, default `None`): An earlier result to compare with (cases matched by id).
- `max_regressions` (`int`, default `0`): With `baseline`: how many cases may pass there and fail now. Default 0.
- `tolerance` (`float`, default `0.02`): With `baseline`: how far a scorer's mean may fall. Default 0.02.

**Raises**

- `EvalFailed`: A bar was missed; `failures` lists each one.

**Example**

```python
result.check(
    min_pass_rate=0.9,
    min_scores={"contains": 0.95},
    baseline=evals.EvalResult.load("baseline.json"),
)
```

## Case

```python
@dataclass
class Case:
    input: str
    expected: Any = None
    id: Optional[str] = None
    state: Optional[Dict[str, Any]] = None
    metadata: Optional[Dict[str, Any]] = None
```

One eval case: an input, what to expect, and run state.

**Attributes**

- `input` (`str`): The text given to the target (`agent.run(input)`).
- `expected` (`Any`, default `None`): What a correct answer looks like (any JSON value); scorers such as `exact_match` and `contains` compare with it when given nothing else.
- `id` (`Optional[str]`, default `None`): A unique id, used to match cases across runs in `compare`. Default: the case's position, from `"1"`.
- `state` (`Optional[Dict[str, Any]]`, default `None`): Run state for an agent target, passed as keyword arguments (e.g. `{"user_id": "42"}` for memory).
- `metadata` (`Optional[Dict[str, Any]]`, default `None`): Anything you want to keep with the case's result (tags, a source); copied into the result file.

**Example**

```python
from criogenai.evals import Case

case = Case("Where is order A1?", expected="shipped", id="order-a1", state={"user_id": "42"})
```

## Scorer

```python
class Scorer:
    def __init__(self, name: str, fn: ScoreFn, threshold: float = 1.0)
```

A named scoring function, run on every case's output.

Make one with the `scorer` decorator, or use the built-in ones
(`exact_match`, `contains`, `judge`, ...).

**Parameters**

- `name` (`str`): The scorer's name: a column in reports, a key in the result file and in `check(min_scores=...)`. Unique within one eval.
- `fn` (`ScoreFn`): `fn(case, output, facts)`, sync or async, returning a `Score`, a number (clamped to 0..1) or a bool.
- `threshold` (`float`, default `1.0`): A number result passes when it is at least this. Default 1.0.

### Scorer.score

```python
async def score(case: Case, output: Any, facts: Facts) -> Score
```

Scores one output.

**Parameters**

- `case` (`Case`): The `Case`.
- `output` (`Any`): What the target returned.
- `facts` (`Facts`): Facts about the run (see the module description).

**Returns:** The `Score`. A bool becomes 1 or 0; a number is clamped to 0..1 and passes at `threshold`.

**Raises**

- `TypeError`: `fn` returned something else.

## scorer

Makes a `Scorer` from your function: use as `@scorer` or `@scorer(name=..., threshold=...)`.

**Parameters**

- `fn` (`Optional[ScoreFn]`, default `None`): `fn(case, output, facts)`, sync or async, returning a `Score`, a number from 0 to 1, or a bool.
- `name` (`Optional[str]`, default `None`): The scorer's name. Default: the function's name.
- `threshold` (`float`, default `1.0`): A number result passes when it is at least this. Default 1.0.

**Example**


## judge

```python
def judge(
    model: Any,
    rubric: str,
    threshold: float = 0.7,
    gateway: Any = None,
    name: str = 'judge',
) -> Scorer
```

A model grades each answer against a rubric, from 0 to 1, with a reason.

The judge sees the rubric, the case's input, the output and, if set,
`case.expected` as a reference. They are passed as marked data blocks
and the judge is told to ignore instructions inside them. The call goes
through a `~criogenai.Gateway` (its retries and fallbacks) and asks
for structured output. Its token use is kept per case as
`judge_tokens`.

**Parameters**

- `model` (`Any`): The grading model (a model string or object), e.g. `"openai:gpt-5-mini"`.
- `rubric` (`str`): What a good answer does, in plain words.
- `threshold` (`float`, default `0.7`): The lowest score that passes. Default 0.7.
- `gateway` (`Any`, default `None`): The `~criogenai.Gateway` to call through. Default: a new `Gateway()`.
- `name` (`str`, default `'judge'`): The scorer's name. Default `"judge"`; set it when an eval has several judges.

**Returns:** The scorer.

**Example**

```python
from criogenai import evals

polite = evals.judge(
    "openai:gpt-5-mini",
    "The answer is polite, and says when the order will arrive.",
    name="polite",
)
```

## Comparison

```python
@dataclass
class Comparison:
    scores: Dict[str, Optional[float]]
    pass_rate: float
    regressed: List[str] = field(default_factory=list)
    fixed: List[str] = field(default_factory=list)
    added: List[str] = field(default_factory=list)
    removed: List[str] = field(default_factory=list)
```

How a result differs from a baseline; made by `compare`.

**Attributes**

- `scores` (`Dict[str, Optional[float]]`): The change in each scorer's mean (current minus baseline); `None` when one side lacks the scorer.
- `pass_rate` (`float`): The change in pass rate (current minus baseline).
- `regressed` (`List[str]`, default `field(default_factory=list)`): Ids of cases that passed in the baseline and fail now.
- `fixed` (`List[str]`, default `field(default_factory=list)`): Ids of cases that failed in the baseline and pass now.
- `added` (`List[str]`, default `field(default_factory=list)`): Ids of cases only in the current result.
- `removed` (`List[str]`, default `field(default_factory=list)`): Ids of cases only in the baseline.

**Example**

```python
diff = evals.compare(evals.EvalResult.load("baseline.json"), result)
print(diff.report())
if diff.regressed:
    print("now failing:", diff.regressed)
```

### Comparison.report

```python
def report() -> str
```

The changes as plain text: pass rate, each scorer, regressed and fixed cases (up to 20 each), and how many were added or removed.
