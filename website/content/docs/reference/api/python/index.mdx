Every public class, function and type of the `criogen` Python package (0.1.6), one page per module, generated from its docstrings and type hints every time the site is built. Install it with `pip install criogen`. The same API in [TypeScript](/docs/reference/api/typescript/) and [Rust](/docs/reference/api/rust/).

New to Criogen? Start with the [quickstart](/docs/quickstart/) and the [agents guide](/docs/guides/agents/); come here for the exact names, parameters and defaults.
