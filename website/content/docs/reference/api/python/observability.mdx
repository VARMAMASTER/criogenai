## Telemetry

Tracing: every run of an agent exported as an
OpenTelemetry trace, to Langfuse or any OTLP/HTTP collector. Message
content is left out unless `capture_content=True`.

```python
from criogen import Telemetry
```

### Telemetry

```python
class Telemetry:
    def __init__(self, spec: Dict[str, Any])
```

An exporter shared by any number of agents: `Agent(..., telemetry=t)`. Exports in the background; call `flush()` before a
script ends, and `shutdown()` when done.

#### Telemetry.langfuse

```python
@staticmethod
def langfuse(
    public_key: Optional[str] = None,
    secret_key: Optional[str] = None,
    base_url: Optional[str] = None,
    capture_content: bool = False,
    service_name: Optional[str] = None,
) -> 'Telemetry'
```

Langfuse (cloud or self-hosted). Keys default to
`LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY` and the address to
`LANGFUSE_BASE_URL`.

#### Telemetry.otlp

```python
@staticmethod
def otlp(
    endpoint: str,
    headers: Optional[Dict[str, str]] = None,
    capture_content: bool = False,
    service_name: Optional[str] = None,
) -> 'Telemetry'
```

Any OTLP/HTTP (JSON) collector, e.g.
`http://localhost:4318/v1/traces`.

#### Telemetry.local

```python
@staticmethod
def local(
    capture_content: bool = False,
    url: str = 'http://127.0.0.1:4318',

```

The local trace viewer (`python -m criogen.trace`).
Content (prompts, outputs) only with `capture_content=True`; it
stays on this computer either way.

#### Telemetry.flush

```python

```

Waits until everything sent so far is exported.

#### Telemetry.shutdown

```python
async def shutdown() -> None
```

Exports what is left and stops.

#### Telemetry.stats

```python
def stats() -> Dict[str, Any]
```

`exported`, `failed`, `dropped` and the `last_error`.

## Trace viewer

The local trace viewer: every run on a page, on your own
computer.

```python
python -m criogen.trace                # http://127.0.0.1:4318

from criogen import Agent, Telemetry
agent = Agent("openai:gpt-5-mini", telemetry=Telemetry.local())
```

Each run's model calls, tool calls and steps on a time axis, with durations,
tokens, cost (from your `prices`) and failures. Prompts and outputs appear
only with `Telemetry.local(capture_content=True)`; nothing leaves the
computer either way. It listens on 127.0.0.1 unless given a `token`.

```python
from criogen import trace

trace.serve(...)
```

These are used as `trace.<name>`.

### serve

```python
def serve(
    port: int = 4318,
    *,
    host: str = '127.0.0.1',
    db: Optional[str] = None,
    keep_runs: Optional[int] = None,
    keep_days: Optional[int] = None,
    prices: Optional[Mapping[str, Mapping[str, float]]] = None,
    token: Optional[str] = None,
) -> TraceViewer
```

Starts the viewer in the background. `db`: a SQLite file (default
`~/.criogen/traces.db`) or `":memory:"`. `prices`: USD per million
tokens by `"provider:model"` or model name, for the cost column.
`token`: required to listen on another address than 127.0.0.1.

## Evals

Evals: run an agent over a set of cases, score each answer,
compare with the last good run, and fail CI when quality drops.

```python
from criogen import evals

data = evals.Dataset.load("cases.jsonl")         # {"input": ..., "expected": ...} per line
result = await evals.evaluate(agent, data, [evals.contains(), evals.tool_called("lookup_order")])
print(result.report())
result.save("eval.json")
result.check(min_pass_rate=0.9, baseline=evals.EvalResult.load("baseline.json"))
```

The result file has the same format in Python, TypeScript and Rust
(`criogen-eval/1`), so a baseline saved by one is read by the others.

```python
from criogen import evals

evals.evaluate(...)
```

These are used as `evals.<name>`.

### evaluate

```python
async def evaluate(
    target: Any,
    dataset: Union[Dataset, Iterable[Any]],
    scorers: Sequence[Scorer],
    *,
    name: str = 'eval',
    concurrency: int = 4,
    timeout: float = 120.0,
    repeats: int = 1,
) -> 'EvalResult'
```

Runs `target` (an Agent, or a function `case -> output`, sync or
async) on every case and scores the outputs. A case that fails or times
out scores 0 with its error kept; the eval goes on.

#### EvalResult.check

```python
def check(
    min_pass_rate: Optional[float] = None,
    min_scores: Optional[Mapping[str, float]] = None,
    baseline: Optional['EvalResult'] = None,
    max_regressions: int = 0,
    tolerance: float = 0.02,
) -> None
```

Raises `EvalFailed` when a bar is missed: a pass rate, a
scorer's mean, or (with `baseline`) a mean that fell by more than
`tolerance` or more than `max_regressions` cases that now fail.

### compare

## Readiness check

`ready()`: one call that says whether Criogen can work here, for start-up
checks and health endpoints. It never raises; it reports. (In Python the
engine is part of the wheel, which pip only installs on systems it runs on,
so if `import criogen` worked the engine loads.)

```python
from criogen import ready, ready_sync
```

### ready

```python
async def ready(model: Any = None, timeout: float = 30.0) -> Dict[str, Any]
```

Checks the engine and, with `model`, that the model answers (one tiny
call, a few tokens). `{"ok", "engine": {...}, "model": {...}}`.

### ready_sync

```python
def ready_sync(model: Any = None, timeout: float = 30.0) -> Dict[str, Any]
```

`ready` for scripts (not inside an event loop).
