## Storage and memory

```ts
import {
  Storage,
  Memory,
  StorageOptions,
  MemoryOptions,
  RetentionOptions,
} from "criogen";
```

### Storage

```ts
class Storage {
  constructor(options?: string | StorageOptions);
}
```

Threads, memory and the audit trail. Agents built with one share it.

#### Storage.url

```ts
readonly url?: string
```

#### Storage.close

```ts
close(): Promise<void>
```

Closes the database's connections (SQLite releases the file). Later calls fail with StorageError.

#### Storage.remember

```ts
remember(namespace: string, key: string, value: unknown, options?: { ttlSecs?: number; }): Promise<void>
```

Saves a fact under `namespace` (e.g. "users/42").

#### Storage.recall

```ts
recall(namespace: string, key: string): Promise<Record<string, unknown> | null>
```

The item, or null.

#### Storage.search

```ts
search(namespace: string, text?: string, limit?: number): Promise<Record<string, unknown>[]>
```

Items in `namespace` and below matching `text` (keywords).

#### Storage.forgetAll

```ts
forgetAll(namespace: string): Promise<number>
```

Deletes everything in `namespace` and below (e.g. one patient).

#### Storage.prune

```ts
prune(): Promise<Record<string, number>>
```

Applies the retention rules once.

#### Storage.auditRecords

```ts
auditRecords(query?: { threadId?: string; action?: string; afterSeq?: number; limit?: number; }): Promise<Record<string, unknown>[]>
```

Audit records, oldest first (needs `audit: true`).

#### Storage.verifyAudit

```ts
verifyAudit(): Promise<{ records: number; ok: boolean; first_broken: number | null; }>
```

Checks the audit trail's hash chain.

### Memory

```ts
class Memory {
  constructor(spec: Record<string, unknown>);
}
```

Long-term memory for an agent: recalled before each model call, and
remember / forget / search_memory tools for the model.

#### Memory.byState

```ts
static byState(key: string, prefix: string, options?: MemoryOptions): Memory
```

One namespace per value of the run's `key` (e.g. per user): `prefix/<value>`.

#### Memory.shared

```ts
static shared(namespace: string, options?: MemoryOptions): Memory
```

One namespace for every run.

#### Memory.semantic

```ts
semantic(embedder: { readonly spec: Record<string, unknown>; }): Memory
```

Searches by meaning with `embedder`: recall and `search_memory` find facts
that say the same thing in other words. If the embedder fails, search
falls back to keywords.

### StorageOptions

```ts
interface StorageOptions {
  /** `undefined` (process memory), "sqlite://path.db" or "postgres://…". */
  url?: string;
  /** "k2:<64 hex>,k1:<64 hex>" (the first is active): encryption at rest. */
  encryptionKeys?: string;
  /** Record who did what. */
  audit?: boolean;
  retention?: RetentionOptions;
  onBusy?: "wait" | "reject" | "interrupt";
  busyTimeoutSecs?: number;
}
```

### MemoryOptions

```ts
interface MemoryOptions {
  recall?: number;
  tools?: boolean;
  ttlSecs?: number;
}
```

### RetentionOptions

```ts
interface RetentionOptions {
  threadTtlSecs?: number;
  keepCheckpoints?: number;
  dropBranches?: boolean;
}
```

## Collections

```ts
import { Collection, CollectionOptions, Document, Hit, CollectionTool } from "criogen";
```

### Collection

```ts
class Collection {
  constructor(name: string, storage: Storage, handle: number);
}
```

Documents searched by meaning. Open one with `Collection.open`.

#### Collection.open

```ts
static open(name: string, options: CollectionOptions): Promise<Collection>
```

Opens collection `name`, building its index from the stored vectors.

#### Collection.add

```ts
add(documents: Document[]): Promise<number>
```

Embeds, stores and indexes documents (an existing id is replaced). Returns how many the collection holds.

#### Collection.search

```ts
search(query: string, options?: { k?: number; where?: Record<string, unknown>; }): Promise<Hit[]>
```

The `k` documents closest in meaning to `query`, best first; `where` keeps only those whose metadata has these values.

#### Collection.remove

```ts
remove(id: string): Promise<boolean>
```

Removes a document; `true` if it was there.

#### Collection.reload

```ts
reload(): Promise<number>
```

Rebuilds the index from storage (another process added documents).

#### Collection.count

```ts
count(): Promise<number>
```

Documents in the index.

#### Collection.close

```ts
close(): Promise<boolean>
```

Forgets the in-memory index (the documents stay stored).

#### Collection.asTool

```ts
asTool(name: string, description: string): CollectionTool
```

This collection as an agent tool: the model gives a `query` (and optionally `k`, up to 20) and gets the hits.

### CollectionOptions

```ts
interface CollectionOptions {
  embedder: Embedder;
  /** A Storage or a URL; in memory without one. */
  storage?: Storage | string;
  /** "flat" (exact, the default) or "hnsw". */
  index?: "flat" | "hnsw";
  /** HNSW only: candidates kept per search (default 64; higher is slower and more accurate). */
  efSearch?: number;
}
```

### Document

```ts
interface Document {
  id: string;
  text: string;
  metadata?: Record<string, unknown>;
}
```

A text to search, with an id and metadata.

### Hit

```ts
interface Hit {
  id: string;
  text: string;
  metadata: Record<string, unknown>;
  score: number;
}
```

A search result: the document and its cosine similarity to the query.

### CollectionTool

```ts
class CollectionTool {
  constructor(collection: Collection, name: string, description: string);
}
```

A collection as an agent tool (`collection.asTool(...)`).
