Every public class, function and type of the `criogenai` TypeScript package (0.1.7), one page per module, generated from its declarations and doc comments every time the site is built. Install it with `npm install criogenai`. The same API in [Python](/docs/reference/api/python/) and [Rust](/docs/reference/api/rust/).

New to CriogenAI? Start with the [quickstart](/docs/quickstart/) and the [agents guide](/docs/guides/agents/); come here for the exact names, parameters and defaults.
