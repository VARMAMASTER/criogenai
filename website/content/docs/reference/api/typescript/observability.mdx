## Telemetry

```ts
import { Telemetry, TelemetryOptions } from "criogen";
```

### Telemetry

```ts
class Telemetry {
  constructor(spec: Record<string, unknown>);
}
```

An exporter shared by any number of agents: `new Agent({ …, telemetry })`.
Exports in the background; call `flush()` before a script ends, and
`shutdown()` when done.

#### Telemetry.langfuse

```ts
static langfuse(options?: TelemetryOptions & { publicKey?: string; secretKey?: string; baseUrl?: string; }): Telemetry
```

Langfuse (cloud or self-hosted). Keys default to LANGFUSE_PUBLIC_KEY /
LANGFUSE_SECRET_KEY and the address to LANGFUSE_BASE_URL.

#### Telemetry.otlp

```ts
static otlp(endpoint: string, options?: TelemetryOptions & { headers?: Record<string, string>; }): Telemetry
```

Any OTLP/HTTP (JSON) collector, e.g. "http://localhost:4318/v1/traces".

#### Telemetry.local

```ts
static local(options?: TelemetryOptions & { url?: string; }): Telemetry
```

The local trace viewer (`npx criogen trace`, `serveTraces()`).
Content only with `captureContent: true`; it stays on this computer either way.

#### Telemetry.flush

```ts
flush(): Promise<void>
```

Waits until everything sent so far is exported.

#### Telemetry.shutdown

```ts
shutdown(): Promise<void>
```

Exports what is left and stops.

#### Telemetry.stats

```ts
stats(): { exported: number; failed: number; dropped: number; lastError: string | null; }
```

Exported, failed and dropped counts, and the last error.

#### Telemetry.toJSON

```ts
toJSON(): Record<string, unknown>
```

### TelemetryOptions

```ts
interface TelemetryOptions {
  /** Send message text and tool arguments too (default false). */
  captureContent?: boolean;
  /** The `service.name` of the traces. */
  serviceName?: string;
}
```

### TraceViewer

```ts
interface TraceViewer {
  /** The page's address. */
  readonly url: string;
  stop(): Promise<void>;
}
```

A viewer serving in the background.

### TraceViewerOptions

```ts
interface TraceViewerOptions {
  /** Default 4318 (OTLP/HTTP's port); 0 picks a free one. */
  port?: number;
  /** Default "127.0.0.1"; anything else needs a `token`. */
  host?: string;
  /** A SQLite file (default ~/.criogen/traces.db) or ":memory:". */
  db?: string;
  keepRuns?: number;
  keepDays?: number;
  /** USD per million tokens by "provider:model" or model name, for the cost column. */
  prices?: Record<string, { input?: number; output?: number }>;
  /** Clients must send `Authorization: Bearer <token>`. */
  token?: string;
}
```

## Evals

Evals: run an agent over a set of cases, score each answer,
compare with the last good run, and fail CI when quality drops.

  &#105;mport \{ evals \} from "criogen";
  const data = await evals.Dataset.load("cases.jsonl");
  const result = await evals.evaluate(agent, data, [evals.contains(), evals.toolCalled("lookup_order")]);
  console.log(result.report());
  await result.save("eval.json");
  result.check(\{ minPassRate: 0.9, baseline: await evals.EvalResult.load("baseline.json") \});

The result file has the same format in Python, TypeScript and Rust
(`criogen-eval/1`), so a baseline saved by one is read by the others.

```ts
import { evals } from "criogen";
evals.evaluate
```

These are used as `evals.<name>`.

### evaluate

```ts
function evaluate(target: Target, dataset: Dataset | Iterable<string | Case>, scorers: Scorer[], options?: EvaluateOptions): Promise<EvalResult>
```

Runs `target` (an Agent, or a function `case -> output`) on every case and scores the outputs.
A case that fails or times out scores 0 with its error kept; the eval goes on.

### Dataset

```ts
class Dataset {
  constructor(cases: Iterable<string | Case>);
}
```

Cases to run: from a list, or `Dataset.load` a JSONL / JSON file (Node).

#### Dataset.load

```ts
static load(path: string): Promise<Dataset>
```

A `.jsonl` file (one case per line) or a `.json` file (a list, or `{"cases": [...]}`).

#### Dataset.cases

```ts
readonly cases: (Case & { id: string; })[]
```

### Case

```ts
interface Case {
  input: string;
  expected?: unknown;
  id?: string;
  state?: Record<string, unknown>;
  metadata?: Record<string, unknown>;
}
```

One input, what to expect, and run state.

### Score

```ts
interface Score {
  value: number;
  pass: boolean;
  reason: string | null;
}
```

A scorer's verdict: `value` from 0 to 1, whether it passed, and why.

### Facts

```ts
interface Facts {
  toolCalls: string[];
  modelCalls: number;
  tokens: { input: number; output: number };
  durationMs: number;
  models: { provider: string; model: string; usage: Record<string, number> }[];
  judgeTokens?: { input: number; output: number };
}
```

What a run did, for scorers.

### ScoreFn

```ts
type ScoreFn = (c: Case, output: unknown, facts: Facts) => Score | number | boolean | Promise<Score | number | boolean>;
```

### Scorer

```ts
interface Scorer {
  readonly name: string;
  score(c: Case, output: unknown, facts: Facts): Promise<Score>;
}
```

A named scoring function.

### scorer

```ts
function scorer(name: string, fn: ScoreFn, threshold?: number): Scorer
```

Your own scorer: a function returning a Score, a number (passes at `threshold`) or a bool.

### exactMatch

```ts
function exactMatch(options?: { ignoreCase?: boolean; }): Scorer
```

The output equals `expected` (both trimmed).

### contains

```ts
function contains(needles?: string[], options?: { ignoreCase?: boolean; }): Scorer
```

The output contains every needle (default: `expected`, a string or a list). The value is the share found.

### regex

```ts
function regex(pattern?: string): Scorer
```

The output matches `pattern` (default: `expected`) somewhere.

### oneOf

```ts
function oneOf(options?: string[], settings?: { ignoreCase?: boolean; }): Scorer
```

The output (trimmed) is one of `options` (default: `expected`, a list).

### jsonValid

```ts
function jsonValid(): Scorer
```

The output is JSON (or already a value).

### jsonSchema

```ts
function jsonSchema(schema: Record<string, unknown>): Scorer
```

The output (JSON) matches `schema`, checked by the engine's validator.

### jsonEquals

```ts
function jsonEquals(path?: string): Scorer
```

The output (JSON), or its field at `path` ("a.b.0"), equals `expected`.

### toolCalled

```ts
function toolCalled(name: string, min?: number): Scorer
```

The agent called tool `name` at least `min` times.

### toolNotCalled

```ts
function toolNotCalled(name: string): Scorer
```

The agent never called tool `name`.

### maxToolCalls

```ts
function maxToolCalls(n: number): Scorer
```

At most `n` tool calls.

### maxModelCalls

```ts
function maxModelCalls(n: number): Scorer
```

At most `n` model calls.

### maxLatency

```ts
function maxLatency(ms: number): Scorer
```

The case took at most `ms` milliseconds.

### maxTokens

```ts
function maxTokens(n: number): Scorer
```

At most `n` tokens in and out together.

### maxCost

```ts
function maxCost(usd: number, prices: Record<string, { input?: number; output?: number; }>): Scorer
```

At most `usd` dollars from your prices (USD per million tokens by "provider:model" or model name). Fails when a model has no price.

### judge

```ts
function judge(model: Model, rubric: string, options?: { threshold?: number; gateway?: Gateway; name?: string; }): Scorer
```

A model grades the answer against `rubric` (0 to 1, with a reason) through the Gateway. Passes at `threshold`.

### EvaluateOptions

```ts
interface EvaluateOptions {
```

## Readiness check

```ts
import { ready, ReadyReport, ReadyOptions } from "criogen";
```

### ready

```ts
function ready(options?: ReadyOptions): Promise<ReadyReport>
```

Checks the engine loads and, with `model`, that the model answers.

### ReadyReport

```ts
interface ReadyReport {
  /** Everything checked is fine. */
  ok: boolean;
  /** The engine (the native addon, or WebAssembly in a browser): loads here or not. */
  engine: { ok: boolean; platform: string; arch: string; libc: string | null; error?: string; code?: string };
  /** Only when a model was given: its credentials work and it answered. */
  model?: { ok: boolean; model: string; latencyMs: number; error?: string; code?: string };
}
```

### ReadyOptions

```ts
interface ReadyOptions {
  /** Also call this model once with a tiny prompt (spends a few tokens). */
  model?: Model;
  /** Give up on the model check after this long (default 30 s). */
  timeoutMs?: number;
  /**
   * Browser only: where the WebAssembly engine is, when it is not next to the
   * script (a URL, a `Response`, its bytes, or a compiled `WebAssembly.Module`).
   */
  wasm?: unknown;
}
```
