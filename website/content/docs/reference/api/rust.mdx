The Rust reference is rustdoc's own: every public item of the crates below, with its documentation, signatures and examples, built from the doc comments every time the site is built. Back to the [API reference](/docs/reference/api/).

| Crate | What it is |
|---|---|
| [`criogenai-agent`](/rustdoc/criogen_agent/) | Agents for CriogenAI: the model and tools loop on the workflow engine |
| [`criogenai-core`](/rustdoc/criogen_core/) | Execution engine for CriogenAI workflows |
| [`criogenai-providers`](/rustdoc/criogen_providers/) | Model provider layer for CriogenAI: messages, tools, model errors, protocols |
| [`criogenai-storage`](/rustdoc/criogen_storage/) | Threads, checkpoints and storage backends for CriogenAI |
| [`criogenai-telemetry`](/rustdoc/criogen_telemetry/) | OpenTelemetry and Langfuse export for CriogenAI runs |
| [`criogenai-gateway`](/rustdoc/criogen_gateway/) | An OpenAI-compatible LLM gateway on CriogenAI's provider layer |
| [`criogenai-trace`](/rustdoc/criogen_trace/) | A local trace viewer for CriogenAI runs: an OTLP receiver with a page |
| [`criogenai-rt`](/rustdoc/criogen_rt/) | Tasks and timers for CriogenAI: Tokio on servers, the JavaScript event loop in the browser |

Start with `criogenai_agent` (agents and tools) and `criogenai_core` (the workflow engine). The crates are not on crates.io yet: use them from [the GitHub repository](https://github.com/VARMAMASTER/criogenai), where the source is. Every page links to its source. Use the search box on any of these pages to find a type or function.

Python and TypeScript have the same features: [Python API](/docs/reference/api/python/), [TypeScript API](/docs/reference/api/typescript/).
