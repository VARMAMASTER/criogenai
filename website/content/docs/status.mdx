change before 1.0. This page is kept accurate: if something is not marked
<span class="status-built">built</span>, do not rely on it.

**About 0.1.5:** it was built on Windows. On npm and PyPI, Windows and the
browser engine (`criogen/web`) have everything marked 0.1.5. On Linux and
macOS, pip installs 0.1.3 and npm runs the 0.1.3 engine (the new features
then say they need engine 0.1.5) until their builds run again, after
15 November.

## Platforms

Tested on Windows x64 and Linux x64. Builds for Linux ARM64 and macOS
(Apple Silicon and Intel) are set up but not yet tested.
In the browser: tested in Chromium, Firefox and WebKit (Safari's engine),
and in Web Workers. Edge runtimes (Cloudflare Workers, Vercel Edge) are not
yet tested.
